# falcon

A vision system that watches a garden, identifies which animal is in it, and
escalates to a deterrent — with a drone as one pluggable effector among
several, not as the foundation.

Planning stage. **Start with [PLAN.md §0](docs/PLAN.md#0-kiss-and-yagni--read-this-before-building-anything)**
— it says which of the following is meant to be built (very little of it) and
which is reasoning on file (most of it).

- **[CLAUDE.md](CLAUDE.md)** — working agreements: KISS, YAGNI, and the two
  places complexity is justified
- **[docs/PLAN.md](docs/PLAN.md)** — the plan: site, camera math, detection
  pipeline, engagement policy, milestones
- **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)** — UML deployment view; what runs
  where and how it communicates
- **[docs/COMPONENTS.md](docs/COMPONENTS.md)** — every component: what it does,
  what it's built on, what it talks to, how it fails
- **[docs/TECH_STACK.md](docs/TECH_STACK.md)** — pinned versions and the
  version policy
